# Astral Shard gift pack

This pack is formatted for `internal/app/giftpack` and includes one base gift
plus an upgrade pool (models, patterns, and backdrops). The animation source is
the Astral Shard asset (`5933629604416717361`) from the supplied Changes CDN.

Upload `astral-shard-pack.zip` in Admin → Gifts → Import gift pack. Enter a
reason, click Validate, then Confirm import. The import is deliberately a
dry-run followed by an idempotent command confirmation.
